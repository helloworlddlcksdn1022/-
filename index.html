데이터

저장된 API 응답과 지역 원본 캐시를 삭제합니다.

데이터 출처: 나이스 교육정보 개방 포털. 내 학교·화면 테마·취향·설정형 API 키는 이 브라우저에만 저장됩니다. 서울·경기 교육지원청 구분은 학교 주소를 이용한 보조 매핑을 포함합니다. 오늘 급식 지도는 주소의 구/시·군 단위 상대 위치를 이용한 분석용 SVG 지도이며 정확한 캠퍼스 좌표가 아닙니다. 현재 날짜가 포함된 급식 캐시는 짧게 유지하고 과거 데이터만 장기 보관합니다. 육류·채소·취향 분류는 이 프로그램의 메뉴명 규칙 기반 분석이며 식재료 중량이나 실제 학생 만족도와 동일하지 않습니다.
